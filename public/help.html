05

常见问题

Q1云声是官方的吗？
不是。云声是第三方开源客户端，依据公开的重构方案自行实现，与网易云音乐官方无隶属或合作关系。
Q2需要开会员才能听歌吗？
不需要。音质跟随你账号本身的权益，普通账号也能正常播放，只是可用音质档位不同——云声内置音质降级链，遇到档位不可用会自动降级而不是报错。
Q3支持哪些手机？
只提供 Full arm64（arm64-v8a）单 ABI 构建，最低 Android 9（API 28），编译目标 Android 16（API 36）。32 位老旧设备没有对应安装包。
Q4登录方式有哪些？
以 WebView 加载官方登录页为主，扫码为兜底；0.2.42 起 QQ 支持原生授权并自动回跳原登录页完成校验。微信、微博等仍走官网流程，是否原生回跳取决于系统「打开链接」设置。
Q5离线缓存占内存吗？能清吗？
音频缓存在应用私有持久目录，不设应用层容量上限、不按使用时间自动淘汰，实际只受手机剩余空间限制。设置里的「清理内容缓存」只清封面和歌词，不动歌曲音频；要彻底清空需卸载应用或清除应用数据。
Q6怎么升级？会丢数据吗？
「设置 → 检查更新」会拉取 GitHub 上的正式 Release，校验包名、签名一致且 versionCode 更高后才允许安装，因此可覆盖升级，登录态、歌单与音频缓存都保留。云声不会降级到更旧的版本。
Q7发现 Bug 或有建议怎么办？
到 GitHub 仓库提 Issue，附上复现步骤、机型与版本号（版本号在「设置 → 关于」）。更新说明里写的验证范围只覆盖当次改动，未验证到的部分不代表已实现。
